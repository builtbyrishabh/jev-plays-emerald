# Jev Plays Emerald

Watch Jev play a real Pokémon Emerald game, from the configured New Game opening through the first Route 103 rival battle.

Jev chooses every move of the game: which door to walk through, who to talk to, which starter to take, and how to fight. Python enumerates what is mechanically possible on the current map - its exits, people and signs - and reuses PokéBot Gen3 navigation, menus, healing, and emulator inputs to carry the choice out. Gender selection, the clock menu and mandatory cutscene dialogue are deterministic; Jev confirms the requested player name. There is no hardcoded route.

## Run locally

The verified target is Apple Silicon macOS, Python 3.13, and the unmodified English Emerald ROM with SHA-1 `f3ae088181bf583e55daf962a92bb46f4f1d07b7`.

```bash
brew install mgba
python3.13 scripts/bootstrap.py
```

Put your Vercel AI Gateway key in the ignored `.env` as `AI_GATEWAY_API_KEY`, then launch with your ROM path:

```bash
uv run --env-file .env python -m jev_plays_emerald --rom "roms/Pokemon - Emerald Version (USA, Europe).gba"
```

Open **<http://127.0.0.1:8888/jev/index.html>** for gameplay, decisions, probabilities, HP, and pause/resume. Real Jev calls use your gateway account. ROMs, saves, keys, and recordings stay outside Git.

Existing profiles and saves are preserved. Use `--profile new-run-name` for a separate fresh run. See [setup](docs/setup.md) for dependencies and checkpoint handling, and [viewer details](docs/viewer.md) for controls.

For experimental LLM planning, run `pnpm --dir service install`, then prefix the
launch command with `JEV_PLANNER_MODEL=openai/gpt-5.6-luna`. The planner replaces
authored route hints with an objective and intervenes after three repeated
overworld attempts without story progress. Jev still chooses the actions.
Advice and call count appear in the viewer. See [planner behavior and limits](docs/planner-proposal.md).

Jev confirms the requested player name **Jev** through its decision API. The
keyboard routine enters that exact capitalization; the name is user-specified,
not freely generated by the model.

Jev also receives a bounded transcript read from Emerald's live dialogue
buffer. To test Jev using dialogue and structured game state without a planner
or authored route hints, leave `JEV_PLANNER_MODEL` unset and launch with
`JEV_AUTHORED_HINTS=0`. Mandatory text still advances automatically; Jev uses
what was said when choosing the next meaningful action.

## Scope and evidence

The implementation has completed a continuous input-only New Game-to-rival run with real Jev decisions. Completion requires the actual rival battle victory and a newly set story flag. Loading a completed checkpoint does not count as a new win.

See [measured results](docs/results.md) for repeatability, failures, costs, and remaining limitations. A working integration does not establish that Jev outperforms deterministic rules.
